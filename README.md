# Джарвис

Голосовой ассистент для Windows: слушает микрофон (Vosk + Silero VAD), понимает команды
(локальный классификатор + навыки), отвечает голосом (UtrobinTTS) и умеет вести беседу
(через Ollama).

## Запуск

```
pip install -r requirements.txt
python main.py            # окно с настройками
python main.py --no-gui   # только голос, в консоли
```

Нужно положить рядом:

| Что | Куда | Зачем |
|---|---|---|
| `model.onnx` (UtrobinTTS) | `voice_samples/` | голос Джарвиса |
| модель Vosk (`model_small` или полная `model`) | корень проекта | распознавание речи |
| Ollama + `qwen3:4b-instruct-2507-q4_K_M` | `ollama pull ...` | живой разговор (необязательно) |

Модель VAD (`models/silero_vad.onnx`, 2 МБ) скачивается сама при первом запуске. PyTorch не нужен.

## Что умеет

Полный список с примерами — вкладка **«Команды»** в окне (с поиском; клик по фразе выполняет её).

- программы и проекты: «открой дискорд», «запусти интеллиджей идея», «открой проект X в идее»;
- музыка: «включи песню …» (на YouTube Music включается сразу), «включи музыку для работы»;
- напоминания и таймеры: «напомни через 10 минут …», «напомни в 18:30 …», «поставь таймер на 5 минут»;
  приходят голосом и уведомлением на ПК или в Telegram;
- случайности: «да или нет», «выбери число от 1 до 3», «запусти мне доту, роблокс или геншин»;
- вычисления, заряд батареи, загрузка ПК, сводка дня, сценарии «режим работы / игры / отдыха»;
- разговор: «а ты бы хотел чувствовать?».

## Настройки (вкладка «Настройки»)

- **Громкость голоса Джарвиса** — только его голос, системный звук не меняется.
- **Как часто говорить «сэр»** — процент фраз, в конце которых есть обращение.
- **Уведомления** — ПК / Telegram / оба. Для Telegram создайте бота у @BotFather, вставьте токен,
  напишите боту сообщение и нажмите «Найти Chat ID».
- **Разработка** — папка с проектами и IDE по умолчанию. Название проекта = имя папки.
- Сценарии «режим …» редактируются в `config/modes.json`.

## Как добавить свою команду

Создайте функцию в `commands/skills/` с декоратором `@skill(...)`: шаблон фразы, описание и
примеры. Она сразу заработает и появится во вкладке «Команды». Примеры — `commands/skills/fun.py`.
